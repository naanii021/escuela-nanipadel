# 🏫 Escuela NaniPadel

Proyecto final de 2º DAM - Daniel Iglesias Franco

Aplicación web para la gestión de una escuela de pádel, desarrollada con **React (frontend)**, **Node.js o Spring Boot (backend)**  
y alojada en un **Mini PC N150** como servidor principal.

## 🎯 Objetivos
- Centralizar la información de alumnos, profesores y clases.
- Mejorar la comunicación entre entrenadores y alumnos.
- Automatizar tareas (recordatorios, copias, estadísticas).
- Integrar hardware (N150) y software en un entorno real.

## 🧩 Tecnologías
| Capa | Herramienta |
|------|--------------|
| Frontend | React |
| Backend | Node.js o Spring Boot |
| Base de datos | MySQL o MongoDB |
| Servidor | Mini PC Soyo N150 |
| Automatización | Cron + PM2 |
